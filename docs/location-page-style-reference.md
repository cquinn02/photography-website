## BRAND COLORS QUICK REFERENCE

| Name | Hex Code | Usage |
|------|----------|-------|
| CMQ Blue | #5577a5 | Primary brand color, titles, buttons |
| CMQ Gray Dark | #575757 | Dark backgrounds, button hover |
| CMQ Gray Darker | #383838 | Body text on light backgrounds |
| White | #ffffff | Light backgrounds, text on dark |

## FONT WEIGHTS QUICK REFERENCE

| Weight | Name | Tailwind Class | Usage |
|--------|------|----------------|-------|
| 300 | Light | font-light | Thin headline words |
| 400 | Normal | font-normal | Body text, thin title words |
| 500 | Medium | font-medium | FAQ questions |
| 600 | Semi-bold | font-semibold | Card titles |
| 700 | Bold | font-bold | Bold title words |
| 800 | Extra Bold | - | Hero headline bold words |
| 900 | Black | font-black | CTA titles |

## THE BIG BOLD/THIN HEADLINE PATTERN

This is the signature CMQ style - mixing bold and thin weights:

```tsx
// Example: "PROFESSIONAL HEADSHOTS PHOENIX"
<span className="font-bold">PROFESSIONAL HEADSHOTS</span>   // Bold (700)
<span className="font-normal">PHOENIX</span>                // Normal/Thin (400)

// Example: Hero headline
<span style={{ fontWeight: '800' }}>COMFORTABLE,</span>     // Extra Bold
<span style={{ fontWeight: '400' }}>HEADSHOTS</span>        // Normal/Thin
```
