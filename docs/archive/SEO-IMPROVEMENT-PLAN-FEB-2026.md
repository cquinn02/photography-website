## Key Insights

### What's Working
1. **Corporate/business headshot keywords are strong** — positions #2-5 for core terms
2. **You're the fastest-growing competitor** — +5.96% visibility while top 2 competitors are declining sharply
3. **Homepage carries all the weight** — 10 of 11 keywords land on the homepage
4. **Local pack presence** — appearing in 2 out of 8 possible local pack results

### What Needs Improvement
1. **Only 4 pages rank for anything** — 13 location pages + blog + other pages contribute zero traffic
2. **Homepage is doing too much work** — 10 keywords on one page means diluted relevance
3. **"Acting headshots phoenix" is declining** — the /pricing-actor page ranks #47, not competitive
4. **"Headshots in phoenix az" declining** — losing ground on an important keyword variant
5. **No SERP features captured** — missing Featured Snippets, People Also Ask, Image Pack, AI Overviews
6. **Pricing pages rank very poorly** — positions #47 and #81
7. **No location pages rank at all** — 13 pages exist but contribute nothing

## SEO Improvement Plan

### PHASE 1: Quick Wins (1-2 sessions)
*Leverage what's already working and fix easy problems*

#### 1A. Strengthen declining keywords
- [ ] **"headshots in phoenix az"** — Add "phoenix az" and "phoenix, az" variations to homepage content, meta description, and image alts
- [ ] **"acting headshots phoenix"** — Improve /pricing-actor page title, H1, meta description, and opening paragraph to better target this keyword
- [ ] **"head shots"** — Add "head shots" (two words) as a variation in content where natural

#### 1B. Fix pricing page SEO (positions #47 and #81)
- [ ] **/pricing-individual** (pos #81) — Review and improve title tag, meta description, H1, and opening content. Currently ranking for 2 keywords but very poorly
- [ ] **/pricing-actor** (pos #47) — Same treatment. Ensure "acting headshots phoenix" appears in title and H1

#### 1C. Internal linking improvements
- [ ] Add links FROM location pages TO homepage (passes link equity)
- [ ] Add links FROM homepage TO pricing pages (helps them rank)
- [ ] Add links FROM blog posts TO relevant service pages
- [ ] Ensure every page links to at least 2-3 other pages on the site

### PHASE 3: Capture SERP Features (2-3 sessions)
*Currently missing all major SERP features — big opportunity*

#### 3A. Target "People Also Ask" (6 keywords trigger PAA)
- [ ] Add FAQ schema markup to homepage and key pages
- [ ] Create content that directly answers common questions:
  - "How much do headshots cost in Phoenix?"
  - "What should I wear for a professional headshot?"
  - "How long does a headshot session take?"
  - "What's the difference between a headshot and a portrait?"
- [ ] Use question-and-answer format in content sections

#### 3B. Target Image Pack (3 keywords trigger image results)
- [ ] Ensure all portfolio images have descriptive alt text with keywords
- [ ] Add image structured data (ImageObject schema)
- [ ] Optimize image filenames with keywords (e.g., `phoenix-corporate-headshot-male.webp`)
- [ ] Create an image sitemap or add images to existing sitemap

#### 3C. Target AI Overviews (3 keywords trigger AI results)
- [ ] Structure content with clear, factual statements that AI can extract
- [ ] Use lists, tables, and structured formatting
- [ ] Ensure key information is in the first paragraph of each page

#### 3D. Get Site Links (0 of 7 possible — competitors have them)
- [ ] Improve site structure with clear navigation hierarchy
- [ ] Add descriptive anchor text for internal links
- [ ] Ensure each major page has a unique, descriptive title
- [ ] Implementing proper header navigation (Phase 2A) should help trigger site links

#### 3E. Grow Local Pack presence (2 of 8 — room to grow)
- [ ] Ensure Google Business Profile is fully optimized
- [ ] Match NAP (Name, Address, Phone) exactly across website and Google Business
- [ ] Add LocalBusiness schema with service areas covering all 13 cities
- [ ] Encourage and respond to Google reviews
