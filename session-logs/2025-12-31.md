## Microsoft 365 SMTP Setup Required

**For email to work, update AWS Amplify environment variables:**

```
SMTP_HOST=smtp.office365.com
SMTP_PORT=587
SMTP_USER=cindy@cmqheadshots.com
SMTP_PASSWORD=[App Password - see below]
SMTP_FROM=cindy@cmqheadshots.com
```

**Creating an App Password in Microsoft 365:**
1. Go to https://account.microsoft.com/security
2. Enable 2-factor authentication if not already enabled
3. Go to "Security" → "Advanced security options" → "App passwords"
4. Create new app password for "SMTP"
5. Use this 16-character password as SMTP_PASSWORD

## Session 2: Fix 413 Content Too Large Upload Error

### Problem
- 413 "Content Too Large" error when uploading photos to proof gallery
- 4.96 MB file was failing due to AWS Amplify Lambda limit (~6MB)
- The `serverActions.bodySizeLimit: '50mb'` only applies to Server Actions, not API routes

### Solution Implemented
Changed from direct multipart upload to **presigned URL upload flow**:

1. Client requests presigned URLs from server (small JSON request)
2. Client uploads directly to S3 (bypasses Lambda completely)
3. Client calls finalize endpoint to apply watermark and create DB records

### Files Created
```
src/app/api/admin/proofs/[id]/photos/presign/route.ts   - Returns presigned S3 URLs
src/app/api/admin/proofs/[id]/photos/finalize/route.ts  - Applies watermark, creates DB record
```

### Files Modified
```
src/lib/s3.ts                                           - Added downloadFromS3() function
src/app/admin/proofs/[id]/page.tsx                      - Updated handleFileUpload() for new flow
```

### Upload Flow (New)
```
1. Admin selects files
2. POST /api/admin/proofs/[id]/photos/presign → returns presigned URLs
3. PUT directly to S3 (using presigned URL) → no size limit
4. POST /api/admin/proofs/[id]/photos/finalize → server downloads, adds watermark, re-uploads, creates DB record
```

### Why This Fixes the 413 Error
- The original upload sent the entire file through the Lambda (limited to ~6MB)
- Now the file goes directly to S3 (no size limit)
- Only small JSON requests go through Lambda
