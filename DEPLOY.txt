## AWS Amplify Deployment

### Automatic Deployment
- Connects to GitHub repository: `git@github.com:cquinn02/photography-website.git`
- Deploys automatically on push to `main` branch
- Build environment: Standard (8GiB Memory, 4vCPUs, 128GB Disk)

### Build Configuration
```yaml
version: 1
frontend:
  phases:
    preBuild:
      commands:
        - npm install -g pnpm
        - pnpm install
    build:
      commands:
        - pnpm run build
  artifacts:
    baseDirectory: .next
    files:
      - '**/*'
  cache:
    paths:
      - node_modules/**/*
      - .next/cache/**/*
```

### Manual Deployment Steps
1. **Push to Repository**
   ```bash
   git add .
   git commit -m "Deployment ready"
   git push origin main
   ```

2. **Monitor Build**
   - AWS Amplify automatically detects the push
   - Build process starts (typically 3-5 minutes)
   - Check build logs for any errors

3. **Verify Deployment**
   - Test all pages and functionality
   - Check mobile responsiveness
   - Verify forms and contact information
   - Test all navigation links

## Common Build Issues

### ESLint Errors
- **Issue**: Unescaped quotes in text content
- **Fix**: Replace quotes with HTML entities:
  - `"` → `&quot;`
  - `'` → `&apos;`

### Image Optimization Warnings
- **Issue**: Using `<img>` instead of Next.js `<Image>`
- **Status**: Warnings only, doesn't block deployment
- **Future**: Consider migrating to Next.js Image component

### TypeScript Errors
- **Issue**: Type mismatches or missing types
- **Fix**: Ensure all props and components are properly typed
